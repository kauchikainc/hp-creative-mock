# HP Mock Sample

業種別のホームページモックを提供するNext.js + TypeScriptアプリケーションです。

## プロジェクト概要

HP制作受託業務において、クライアントに業種別のホームページモックを迅速に提供するためのシステムです。会社情報を入力し、業種とプランを選択することで、その情報が反映されたモックサイトをプレビューできます。

## 主な機能

### 入力情報
- 会社名/組織名/屋号（必須）
- 代表者名（任意）
- 郵便番号（任意）
- 都道府県（任意）
- 市区町村（任意）
- 丁目番地（任意）
- 建物名（任意）

※未入力項目にはサンプル値が自動的に表示されます

### 対応業種

**現在対応**:
- 不動産
- 中古車販売

**今後追加予定**:
- 建設業
- 美容院
- 飲食店
- その他、業種ごとに順次追加予定

※業種の追加は容易に行えるよう、拡張性の高い設計を採用しています

### プランの種類

#### Standard プラン
- 基本情報ページ
- ヒーローセクション
- 検索フォーム
- お問い合わせフォーム
- 会社概要

#### Premium プラン
Standard プランの全機能に加えて：
- CMS機能（コンテンツ管理）
- ブログ機能
- お知らせ・ニュース機能
- 在庫管理機能
  - 不動産: 公開中物件情報
  - 中古車: 販売中車両情報、販売実績

## デザイン方針

このプロジェクトのモックは、実際の商用サイトとして違和感のないデザインを目指しています。

### デザイン原則

1. **高品質な画像の使用**
   - 各業種に適した実写画像を配置
   - プレースホルダーではなく、実際に使用できるクオリティの画像を使用

2. **リッチなアニメーション**
   - スクロールアニメーション
   - ホバーエフェクト
   - トランジション効果
   - ローディングアニメーション

3. **AI感の排除**
   - 「いかにもAIが作った」と感じさせないデザイン
   - テキストコンテンツは自然で具体的
   - レイアウトは実際の商用サイトを参考に
   - カラースキームは業種に適した配色

4. **プロフェッショナルな仕上がり**
   - クライアントにそのまま提示できるクオリティ
   - 細部までこだわったUI/UX
   - レスポンシブデザインの徹底

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **アニメーション**: Framer Motion
- **状態管理**: React Hooks + LocalStorage
- **テスト**: Jest + React Testing Library
- **リンター**: ESLint + Prettier

## セットアップ

### 必要環境
- Node.js 18.x以上
- npm または yarn

### インストール

```bash
# リポジトリのクローン
git clone <repository-url>
cd mock_sample

# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

```

├── src/

│   │   ├── page.tsx         # トップ画面（入力フォーム）
```

## テスト駆動開発(TDD)

このプロジェクトはTDDで開発されています。

### テスト方針
1. まずテストを作成
2. テストを実行し、失敗を確認
3. テストが正しいことを確認後コミット
4. テストをパスさせる実装を進める
5. すべてのテストが通過するまで繰り返す

### テストの実行

```bash
# 全テスト実行
npm test

# 特定のテストファイルのみ実行
npm test -- CompanyInfoForm.test.tsx

# カバレッジ表示
npm run test:coverage
```

## 使用方法

### 1. トップ画面で情報入力
- 会社情報を入力（必須は会社名のみ）
- 業種を選択（不動産 / 中古車）
- プランを選択（Standard / Premium）

### 2. モックプレビュー
- 入力した情報が反映されたモックサイトが表示されます
- ナビゲーションバー、フッター、会社概要セクションに情報が表示されます

### 3. URL共有
- 生成されたURLを共有することで、他の人も同じモックを閲覧できます

## URL構造

```
# トップ画面
/

# モックページ
/{業種}/{プラン}

例:
/real-estate/standard
/real-estate/premium
/used-car/standard
/used-car/premium
```

会社情報はLocalStorageに保存され、ページリロード時も保持されます。

## トラブルシューティング

### LocalStorageがクリアされる
ブラウザのプライベートモードでは、LocalStorageが正常に機能しない場合があります。通常モードでご利用ください。

### スタイルが反映されない
Tailwind CSSのビルドエラーの可能性があります。以下を試してください：

```bash
npm run build
```

### テストが失敗する
依存パッケージが正しくインストールされているか確認してください：

```bash
rm -rf node_modules package-lock.json
npm install
```
