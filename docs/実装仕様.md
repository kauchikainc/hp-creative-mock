# HP Mock Sample - 実装仕様書

## 1. システム概要

### 1.1 目的
業種別のホームページモックを迅速に提供し、クライアントへのプレゼンテーション効率を向上させる。

### 1.2 システムアーキテクチャ
- **フロントエンド**: Next.js 14 (App Router) + TypeScript
- **スタイリング**: Tailwind CSS
- **アニメーション**: Framer Motion
- **状態管理**: React Hooks + LocalStorage
- **ルーティング**: Dynamic Routes (`[industry]/[plan]`)
- **データ永続化**: LocalStorage

### 1.3 デザイン方針

このプロジェクトでは、実際の商用サイトとして違和感のないプロフェッショナルなデザインを実装します。

#### デザイン原則

1. **高品質な画像の使用**
   - 各業種に適した実写画像を配置
   - Unsplash、Pexels等から高解像度の画像を使用
   - プレースホルダー画像は使用しない

2. **リッチなアニメーション**
   - Framer Motionを使用したスムーズなアニメーション
   - スクロールトリガーによるフェードイン・スライドイン
   - ホバーエフェクト（scale、opacity、color変更）
   - ページ遷移時のトランジション
   - ローディングアニメーション

3. **AI感の排除**
   - テキストコンテンツは自然で具体的な表現
   - レイアウトは実際の商用サイトを参考
   - カラースキームは業種に適した配色
   - フォントは視認性と美しさを重視
   - 余白とバランスを考慮した洗練されたデザイン

4. **プロフェッショナルな仕上がり**
   - クライアントにそのまま提示できるクオリティ
   - 細部までこだわったUI/UX
   - レスポンシブデザインの徹底
   - アクセシビリティへの配慮

```typescript
export const isPremiumPlan = (plan: Plan): boolean => {
  return plan === PLANS.PREMIUM;

// プラン別機能設定を取得
export const getPlanFeatures = (plan: Plan): PlanFeatures => {
  const baseFeatures: PlanFeatures = {
    hasContactForm: true,
    hasCMS: false,
    hasBlog: false,
    hasNews: false,
    hasInventoryManagement: false,
  };

  if (isPremiumPlan(plan)) {
    return {
      ...baseFeatures,
      hasCMS: true,
      hasBlog: true,
      hasNews: true,
      hasInventoryManagement: true,
      hasSalesHistory: true,
    };
  }

  return baseFeatures;
};
```

```typescript
// 会社情報のバリデーション
export const validateCompanyInfo = (
  info: Partial<CompanyInfo>
): Record<string, string> => {
  const errors: Record<string, string> = {};

  // 会社名は必須
  if (!info.companyName || info.companyName.trim() === '') {
    errors.companyName = '会社名/組織名/屋号は必須です';
  }

  // 郵便番号の形式チェック(入力されている場合のみ)
  if (info.postalCode && !/^\d{3}-?\d{4}$/.test(info.postalCode)) {
    errors.postalCode = '郵便番号の形式が正しくありません (例: 100-0001)';
  }

  return errors;
};

// 郵便番号の正規化（ハイフン自動挿入）
export const normalizePostalCode = (value: string): string => {
  const digits = value.replace(/\D/g, '');
  if (digits.length === 7) {
    return `${digits.slice(0, 3)}-${digits.slice(3)}`;
  }
  return value;
};
```

## 5. カスタムフック

### 5.1 useCompanyInfo (`hooks/useCompanyInfo.ts`)

```typescript
interface UseCompanyInfoReturn {
  companyInfo: CompanyInfo;
  updateCompanyInfo: (info: Partial<CompanyInfo>) => void;
  resetToDefault: () => void;
  isLoaded: boolean;
}

export const useCompanyInfo = (): UseCompanyInfoReturn => {
  const [companyInfo, setCompanyInfo] = useState<CompanyInfo>(DEFAULT_COMPANY_INFO);
  const [isLoaded, setIsLoaded] = useState(false);

  // LocalStorageから読み込み
  useEffect(() => {
    const saved = localStorage.getItem('companyInfo');
    if (saved) {
      try {
        setCompanyInfo(JSON.parse(saved));
      } catch (e) {
        console.error('Failed to parse company info:', e);
      }
    }
    setIsLoaded(true);
  }, []);

  // 更新
  const updateCompanyInfo = useCallback((info: Partial<CompanyInfo>) => {
    setCompanyInfo((prev) => {
      const updated = { ...prev, ...info };
      localStorage.setItem('companyInfo', JSON.stringify(updated));
      return updated;
    });
  }, []);

  // リセット
  const resetToDefault = useCallback(() => {
    setCompanyInfo(DEFAULT_COMPANY_INFO);
    localStorage.setItem('companyInfo', JSON.stringify(DEFAULT_COMPANY_INFO));
  }, []);

  return { companyInfo, updateCompanyInfo, resetToDefault, isLoaded };
};
```

### 5.2 usePlan (`hooks/usePlan.ts`)

```typescript
interface UsePlanReturn {
  plan: Plan;
  features: PlanFeatures;
  isPremium: boolean;
}

export const usePlan = (plan: Plan): UsePlanReturn => {
  const features = useMemo(() => getPlanFeatures(plan), [plan]);
  const isPremium = useMemo(() => isPremiumPlan(plan), [plan]);

  return { plan, features, isPremium };
};
```

```typescript
export async function generateStaticParams() {
  const industries = Object.values(INDUSTRIES);
  const plans = Object.values(PLANS);

  return industries.flatMap((industry) =>
    plans.map((plan) => ({
      industry,
      plan,
    }))
  );
```
